# AIPolicyAssessment2

Economics of Artificial Intelligence Assessment 2 - AI Policy Essay
This repository hold my submission for Econ. of AI Assessment 2. It includes the different versions of essay's adapted through the process off producing this Policy essay.
Each version is processed with a different perspective. With earlier versions focussing on more broader concepts of policy. 
Version 1 is a breif outline of the key topics to be followed for the proposal
Version 2 is a narrative essay, looking back on the Policy proposal from a position in the future, 2035.
Version 3 is a combination of both a narrative driven essay and more defined, informative essay with a larger focus on AI Policy from a government lens and how it effects economic concepts.
